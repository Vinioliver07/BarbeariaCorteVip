# **App Name**: CorteVip Booking

## Core Features:

- Service Catalog: Display a list of available services (haircuts, beard trims, etc.) with descriptions and prices.
- Availability Management: Enable CorteVip to set working days (Monday to Saturday) and hours (8h to 20h).
- Booking Calendar: Allow customers to select a service, view available time slots, and book appointments. Once an appointment is booked for 14h it will be saved.
- Appointment Confirmation: Automatically send a confirmation message to the customer upon booking an appointment.

## Style Guidelines:

- Primary color: Deep Yellow (#D4AF37), inspired by the golden elements of the logo and creating a luxurious aesthetic.
- Background color: Near-black (#1A1A1A), offering a stark contrast that makes the yellow elements pop and conveys a premium feel.
- Accent color: Muted gold (#B8860B), slightly darker than the primary, used for interactive elements to guide the user's eye.
- Font pairing: 'Belleza' (sans-serif) for headlines and short amounts of text, paired with 'Alegreya' (serif) for body text.
- Use simple, elegant icons to represent services and appointment details.
- A clean, single-page layout with clear sections for services, booking, and contact information.
- Subtle transitions and animations to enhance user engagement, such as a loading animation when checking availability.
