# 💈 Barbearia CorteVip

Sistema de agendamento online para barbearia desenvolvido com Next.js 15, TypeScript e TailwindCSS.

## 🚀 Tecnologias

- **Next.js 15** - Framework React
- **TypeScript** - Tipagem estática
- **TailwindCSS** - Estilização
- **NextAuth v5** - Autenticação
- **Shadcn/ui** - Componentes UI
- **React Hook Form** - Formulários
- **Zod** - Validação de dados
- **date-fns** - Manipulação de datas

## 📦 Instalação

```bash
npm install
```

## 🔧 Configuração

1. Configure as variáveis de ambiente no arquivo `.env.local`
2. Execute o servidor de desenvolvimento:

```bash
npm run dev
```

3. Acesse: `http://localhost:9002`

## 🎯 Funcionalidades

- ✅ Agendamento online de serviços
- ✅ Painel administrativo para barbeiros
- ✅ Gerenciamento de agendamentos
- ✅ Integração com WhatsApp
- ✅ Autenticação segura
- ✅ Sistema de cancelamento

## 👨‍💼 Painel Admin

Acesse `/admin` para fazer login no painel do barbeiro.
